# Theory of Computation

**UFRGS - INF05501 - Teoria da Computação N - 2025/1**

## About

This repository documents the four Theory of Computation projects proposed during the semester by the respective University discipline.

* Project 1 - [NORMA Machine](https://archive.org/details/programsmachines0000bird/page/n9/mode/2up). ([*simulator*](https://www.inf.ufrgs.br/~rma/simuladores/norma.html))

* Project 2 - [Lambda calculus](https://en.wikipedia.org/wiki/Lambda_calculus). ([*simulator*](https://www.inf.ufrgs.br/~rma/simuladores/lambda.html))
    
* Project 3 - [Turing Machine](https://en.wikipedia.org/wiki/Turing_machine). ([*simulator*](https://www.inf.ufrgs.br/~rma/simuladores/turing.html))

* Project 4 - [Undecidable problems](https://en.wikipedia.org/wiki/Undecidable_problem).
